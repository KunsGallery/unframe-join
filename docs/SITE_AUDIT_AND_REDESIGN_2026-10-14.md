# Join 사이트 점검 및 개편 제안

점검일: 2026-10-14 / 대상: join.unframe.kr 및 현재 로컬 소스.

## 범위와 한계

운영 사이트의 메인 입구, 살롱 목록·상세, 오픈콜 공개 화면, 관리자 콘솔, 메인 입구 편집, 오픈콜 편집을 읽기 전용으로 확인했다. 메인은 390×844 모바일 화면도 확인했다. 관리자 화면은 익명 상태에서도 열렸으며, 신청자 개인정보·관리자 저장 권한은 확인하지 않았다. 실제 신청, 입금, 메시지 발송, 데이터 변경은 수행하지 않았다. 대관은 메인에서 비활성화되어 실제 신청 흐름 대신 소스를 분석했다. 따라서 전체 사이트의 완전한 기능·접근성 검증을 의미하지 않는다.

## 관리자 콘솔 개편안

### 전체 구조

큰 Control Center 히어로와 반복 통계를 줄이고, 고정 사이드 메뉴와 작업 제목을 사용한다. 모바일은 메뉴 선택 드로어와 한 열 편집으로 전환한다.

- 운영: 신청 현황, 일정, 대관 문의, 협업 문의
- 콘텐츠: 메인 화면, 오픈콜, 살롱
- 설정: 발송 채널, 관리자·권한, 진단

메인 문구·입구·팝업은 메인 화면의 하위 탭으로 통합한다. 오픈콜 완료 화면·접수 알림은 해당 공고 내부에서 관리한다. 시스템 설정에는 API 연결과 테스트 등 전역 기능만 둔다.

### 메인 입구 편집

왼쪽에는 4개 입구의 작은 목록, 가운데에는 단일 편집 폼, 오른쪽에는 실제 공개 컴포넌트의 데스크톱·모바일 프리뷰를 둔다. 같은 항목의 입력란은 한 곳에만 둔다.

- 공개 여부: 표시 / 숨김
- 접수 상태: 준비 중 / 접수 중 / 접수 마감
- 제목·설명·이미지·버튼 문구
- 실제 연결 페이지와 바로가기
- 순서: 위·아래 이동 및 드래그
- 상태에 따른 기본 문구 자동 적용, 사용자 지정 문구는 별도 선택
- 상단 저장 바: 변경 있음 / 저장됨, 되돌리기, 저장

페이지 열람과 접수 가능 여부를 분리한다. 마감이어도 상세 정보·지난 기록은 볼 수 있고 신청 버튼만 비활성화된다. 공개 설정이 실제 연결 없는 입구를 ACTIVE로 만들지 못하도록 검사한다. 이미지 URL 대신 업로드·교체·삭제를 제공한다.

### 오픈콜 관리

공고 목록을 먼저 보여주고 하나를 선택하면 해당 공고 작업 화면으로 이동한다. 선택한 공고 ID를 URL에 보존해 새로고침·직원 공유가 가능하게 한다.

작업 탭: 기본 정보 / 모집 요강 / 신청폼 / 완료·알림 / 지원자 / 공개 설정.

공개 여부, 접수 상태, 대표 공고 지정은 서로 다른 설정으로 제공한다. 공개 상세 /opencall/:slug, 신청 /opencall/:slug/apply를 만들어 공개 대표가 아닌 공고도 공유할 수 있게 한다. /opencall은 공고 목록 또는 명확한 대표 페이지로 정한다.

폼에서는 문항 선택 후 제목·설명·형식·선택지·필수·표시·폭을 같은 편집 영역에서 수정한다. 실제 신청폼 렌더러를 프리뷰에 사용한다. 위·아래 이동, 복제, 이미지 문항을 일관되게 지원한다.

‘기본 잔상 공고 생성’은 ‘새 공고 만들기’와 ‘기존 공고 복제’로 바꾼다. 기본 문서 덮어쓰기 도구는 진단 화면으로 옮긴다. 저장과 공개를 구분하고, 날짜 역전·대표 중복·필수 질문 오류만 공개 전에 검사한다.

지원자 목록은 표 중심으로 이름·접수일·상태·담당자·다음 조치를 빠르게 비교한다. 상세에는 원래 질문 순서로 답변을 표시하고, 승인·거절·추가자료 요청을 선택했을 때 해당 입력 영역만 연다. 발송 상태와 심사 상태는 각각 표시한다.

## 공간 대관 상세페이지 제안

추천 경로: /rental → /rental/apply. 페이지 목적은 공간이 내 행사에 적합한지, 어떤 비용과 절차인지 판단하도록 돕는 것이다.

1. 실제 공간 대표 사진과 ‘UNFRAME 공간 대관’. 위치·운영 형태와 ‘대관 문의하기’ 버튼.
2. 공간 사진 갤러리: 전시장 전체, 벽면, 입구, 촬영·팝업·토크 실제 배치. 평면도 원본 보기.
3. 공간 정보: 면적, 층고, 벽면, 권장 인원, 운영 시간, 전력·조명·음향·인터넷, 반입 동선, 접근성. 확인된 값만 표시.
4. 이용 유형: 전시 / 팝업·쇼룸 / 촬영 / 토크·워크숍. 유형을 고르면 해당 조건과 사례를 보여준다.
5. 비용: 기본 공간 이용료와 기획·디렉팅·상주 운영 옵션을 분리. 산정 단위·부가세·추가 비용·최소 기간·보증금은 운영 기준 확정 후 기재.
6. 일정: 가능한 기간 확인. 일정 미정 선택 가능. 문의 제출이 예약 확정이 아니라는 안내.
7. 사례: 실제 사진, 행사 유형, 기간, 이용 방식. 공개 가능한 사례만 사용.
8. 절차: 문의 → 일정·적합성 검토 → 견적·조건 안내 → 계약·입금 → 반입·운영·철수.
9. 이용 조건·FAQ: 소음, 음식, 벽 고정, 설치, 취소, 파손, 운송, 주차.

문의폼: 개인/팀·브랜드, 담당자, 연락처, 회신 이메일, 이용 목적, 희망 기간·시간(미정 가능), 인원, 공간 활용 계획, 필요한 장비, 예산 범위(미정 가능), 선택 첨부, 동의.

기존 FOR-CONTEXT 등 전시 패키지는 ‘전시 기획·운영 지원’ 선택지로 보존하되 촬영·워크숍 이용자에게 필수 선택으로 강요하지 않는다. 완성된 작품 목록·고화질 작품 이미지는 최초 공간 문의의 필수 자료에서 제외하고 필요 시 후속 요청한다.

관리자는 공간 사진·정보·이용 유형·요금·FAQ·차단 일정·문의 상태를 수정할 수 있어야 한다. 확정 일정과 문의 중 일정은 구분한다.

## 협업 문의 상세페이지 제안

추천 경로: /collaboration → /collaboration/apply. 일정이 정해지지 않은 초기 제안도 받을 수 있도록 설계한다.

1. ‘UNFRAME 협업 제안’과 실제 공동 프로젝트 이미지. 함께 만들고 싶은 결과를 제안하도록 안내.
2. 협업 분야: 공동 기획 전시, 브랜드·콘텐츠, 음악·OST, 매거진·인터뷰, 기술·인터랙티브 프로젝트. 실제 운영하는 분야만 채택.
3. 프로젝트 사례: 무엇을 만들었고 각 파트너가 무엇을 맡았는지 설명. UP·U#·U.A.U 등 약어는 설명과 사례를 연결한다.
4. 역할: UNFRAME이 제공 가능한 공간·기획·콘텐츠·운영 범위와 상대에게 기대하는 제안 정보.
5. 진행: 제안 접수 → 적합성 검토 → 미팅 → 역할·예산 협의 → 실행. 회신 기한은 운영팀이 정한 값만 표시.
6. FAQ: 아이디어 단계 가능 여부, 비용·수익배분 협의, 공간 대관과의 차이, NDA 필요 시 문의.

문의폼: 담당자·팀/브랜드명, 연락처·이메일, 협업 분야, 제안 제목, 아이디어·목표, 대상, 희망하는 UNFRAME 역할, 제공 가능한 자원, 일정(미정 가능), 예산(미정 가능), 참고 링크·선택 첨부, 동의.

첫 제출에서 사업계획서·작품 목록·확정 일정을 요구하지 않는다. 완료 화면은 ‘제안 접수’와 후속 연락 방식만 안내하며 협업 확정으로 오해할 표현은 피한다.

데이터는 trackType: collaboration으로 구분하고, 관리자·마이페이지에 독립 분류를 둔다. 문의 상태는 접수 / 검토 중 / 미팅 제안 / 조건 협의 / 진행 확정 / 종료로 운영한다. 대관 날짜 예약을 생성하지 않는다.
